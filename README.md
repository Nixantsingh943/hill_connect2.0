# 🌄 About

HillConnect is a community-first web platform designed specifically for people living in mountainous and remote regions.

Many villages face challenges such as limited transportation, expensive equipment, lack of accommodation for travelers, and poor communication among communities.

HillConnect aims to solve these challenges by bringing everything together on one platform.

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/HillConnect.git
```

Frontend

```bash
cd client
npm install
npm run dev
```

Backend

```bash
cd server
npm install
npm run dev
```

Create a `.env`

```env
PORT=5001

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET
```
